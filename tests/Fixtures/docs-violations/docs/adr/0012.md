# ADR-0012: PostgreSQL baseline

## Статус

accepted (D15)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D15.

## Решение

PostgreSQL 16 и выше — основной профиль конкурентности; SQLite допустим для unit/arch. Другие профили требуют квалификации.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Обещать другие СУБД без проверки нельзя.
