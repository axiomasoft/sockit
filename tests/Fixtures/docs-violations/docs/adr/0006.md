# ADR-0006: Нативное социальное состояние

## Статус

accepted (D2, D14)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D2, D14.

## Решение

Posts, revisions, feed, social reactions и groups принадлежат соответствующим модулям SocKit. Историческое упоминание comments в D2 заменено D14.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Хранение posts в Chatom отклонено.
