# ADR-0004: Комментарии вне SocKit

## Статус

accepted (D14)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D14.

## Решение

Chatom Comments и Forum владеют телом, деревом, lifecycle и модерацией; SocKit не реализует comments. Production readiness внешнего API не предполагается. D14 заменяет D1, D3 и D7.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Native comments и sockit-comments отклонены по последней директиве владельца.
