# ADR-0014: Снимки схем панели

## Статус

accepted (D15)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D15.

## Решение

Модули владеют schema fragments; consumer владеет frozen migration snapshots и моделями каждой панели. Удаление конфигурации не удаляет данные.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

DDL на каждый объект хоста и runtime schema mutation отклонены.
