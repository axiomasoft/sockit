# ADR-0005: Условные внешние интеграции

## Статус

accepted (D14)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D14.

## Решение

Интеграции включаются при подтверждённом публичном контракте и потребителе; standalone reactions/posts не требуют соседей.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Обязательные зависимости нарушили бы автономность ядра.
