# ADR-0002: Механизмы ядра

## Статус

accepted (D4)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D4.

## Решение

Ядро содержит только механизмы, включая Panels; reactions, posts и groups — отключаемые модули. Минимальный потребитель — reactions на объекте хоста.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Обязательные функции в ядре увеличили бы минимальную установку.
