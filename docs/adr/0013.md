# ADR-0013: Контекст worker

## Статус

accepted (D15, D16)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D15, D16.

## Решение

Immutable registry не хранит actor, installation или current panel; операция получает явный контекст, worker повторно разрешает его и авторизует доступ.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Singleton с mutable контекстом допускает утечки между запросами.
