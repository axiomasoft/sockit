## Предложение канону

Предлагаемая CD-16: SocKit владеет panels, reactions, posts/feed и optional groups; discussion body/tree/lifecycle — Chatom Comments/Forum. Один state writer; optional public adapters не копируют обсуждение. Panel, storage, surface и tenant — отдельные оси; общие conformance practices не требуют общего runtime. Предыдущая локальная идея sockit-comments отменена D14. Это предложение, внешние документы и соседние пакеты не изменены.
