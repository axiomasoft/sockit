# ADR-0011: Receipts, outbox и tombstones

## Статус

accepted (D15)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D15.

## Решение

Ключ и digest обеспечивают идемпотентность; CAS, state, receipt и outbox атомарны; сеть после commit, tombstone и incarnation исключают воскрешение.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Повтор с новым ключом при unknown и сеть под lock небезопасны.
