# ADR-0010: Условная зависимость Forum

## Статус

accepted (D9, D14)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D9, D14.

## Решение

При включении P7 отдельный модуль зависит от подтверждённого публичного API Forum; Forum владеет обсуждениями и голосами.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Зависимость ядра и повторная реализация форума отклонены.
