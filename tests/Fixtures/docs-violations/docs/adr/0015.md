# ADR-0015: Безопасная генерация

## Статус

accepted (D15)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D15.

## Решение

Генератор проверяет все выходные файлы до записи, не перезаписывает их и делает additive upgrade с детерминированными идентификаторами.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Неявная перезапись и destructive upgrade отклонены.
