# ADR-0008: Текущая аудитория

## Статус

accepted (D6, D16)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D6, D16.

## Решение

Доверенная installation, panel и target, admission и containment проверяются до allow. Авторство не обход; неизвестное запрещено, архив read-only.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Rank — только грубый floor, не доказательство включения множеств; общая algebra отложена.
