# Философия

SocKit — встраиваемый social engine для Laravel: независимые панели и социальные модули для сущностей хоста. Наблюдение 2026-10-17: подход к качествам и deletion test адаптирован из практики Chatom.

## Проверяемые качества

- Компактность: минимальный потребитель reactions работает без posts, groups и внешних интеграций; каждый механизм проходит deletion test.
- Расширяемость: хост использует публичные API/SPI, каждая заявленная ось имеет потребителя и swap-тест.
- Надёжность: у каждого состояния один writer; атомарный конверт и конкурентные сценарии проверяются тестами.
- Конфигурируемость: providers и class-string задаются без правки пакета; config:cache работает; surface связывается с произвольной сущностью хоста.

## Чем SocKit не является

SocKit не является SaaS, UI, identity/RBAC/tenancy движком, хранилищем файлов или движком комментариев и форума. Поиск, ranking и SDK — отдельные треки.
