# ADR-0001: Транзакции панели

## Статус

accepted (D15)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D15.

## Решение

Каждая панель использует одно соединение для состояния, revision, receipt, outbox и tombstone. Межпанельной атомарности нет.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Межсоединённая транзакция не обещается.
