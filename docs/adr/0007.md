# ADR-0007: Панели и поверхности

## Статус

accepted (D15)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D15.

## Решение

Provider и builder компилируются в frozen definition и storage; panel identity присутствует в ссылках и границах. Surface instance — сущность хоста внутри панели. D15 заменяет D5 и D13.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Глобальные connection и prefix не заменяют per-panel storage.
