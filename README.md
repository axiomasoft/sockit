# SocKit

SocKit is an embeddable social engine for Laravel. The project is pre-1.0; its public API is not yet released.

## Статус и что дальше

P1 defines the core contracts, panel and surface configuration, fixtures, architecture boundaries and checks. These are contract-level evidence, not end-to-end or production readiness. Runtime, persistence and the social modules follow in P2–P6; Forum and Chatom integrations are conditional. See the [traceability matrix](docs/architecture/traceability.md) for requirements, evidence and pending work.
