# ADR-0003: Модули и публичные границы

## Статус

accepted (D4)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D4.

## Решение

Модули подключаются через реестр и публичные Api/Spi; Internal не является контрактом.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Sibling imports и общий обязательный plugin runtime не принимаются.
