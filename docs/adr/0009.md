# ADR-0009: Различные владельцы реакций

## Статус

accepted (D8)

## Контекст

Граница SocKit и требования совместимости зафиксированы действующими решениями D8.

## Решение

Social reaction принадлежит SocKit, message reaction — Chatom, forum vote — Forum; автоматического зеркала нет.

## Последствия

Реализация и проверки следующих фаз обязаны соблюдать эту границу; этот ADR сам по себе не подтверждает готовность runtime.

## Альтернативы

Общий writer нарушил бы независимые state identities.
